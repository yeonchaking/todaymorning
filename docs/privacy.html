오늘도출근 개인정보처리방침

시행일: 2026년 8월 3일

「오늘도출근」(이하 "본 앱")은 사용자의 개인정보를 소중히 여기며, 관련 법령을 준수합니다. 본 방침은 본 앱이 어떤 정보를 다루고 어떻게 보호하는지 설명합니다.

핵심 요약
본 앱은 회원가입이 없으며 이름·이메일·전화번호 등 개인을 식별할 수 있는 정보를 수집하지 않습니다. 알람·미션 설정과 기록은 사용자의 기기에만 저장됩니다.
다만 실시간 버스·지하철 도착정보 조회와 지도 표시를 위해, 정류장 식별자·역명·위치 좌표 등 일부 정보가 외부 API 서버로 전송됩니다. 자세한 내용은 4항을 참고해 주세요.

1. 수집하는 개인정보

본 앱은 이름, 이메일, 전화번호, 계정 정보 등 개인을 식별할 수 있는 정보를 수집하지 않습니다. 회원가입이나 로그인 절차가 없으며, 사용자 계정을 만들지 않습니다.

본 앱은 개발자가 운영하는 서버를 두고 있지 않습니다. 아래 4항에 기재된 외부 API 호출을 제외하면 데이터가 기기를 벗어나지 않습니다.

2. 기기에 저장되는 데이터

아래 데이터는 앱 기능 제공을 위해 사용자 기기 내부에 저장됩니다.

데이터용도
알람 설정 (시각, 요일, 알람음, 진동 등)출근 알람 제공
집·회사 위치 (사용자가 주소 검색으로 직접 선택한 좌표와 주소)출근 경로 및 미션 설정
미션 설정 (선택한 정류장·역, 노선, 목표 시각)타임어택 미션 및 실시간 도착정보 표시

이 데이터는 개발자에게 전송되지 않으며, 개발자가 열람할 수 없습니다.

3. 위치 정보

본 앱은 정류장 선택 화면에서 내 위치 주변의 버스 정류장을 찾을 수 있도록 위치 권한(ACCESS_FINE_LOCATION, ACCESS_COARSE_LOCATION)을 사용합니다.

  • 위치 정보는 정류장 선택 화면에서만 사용되며, 지도를 내 위치로 이동하는 데 쓰입니다.
  • 이때 해당 좌표는 주변 정류장 목록을 받아오기 위해 서울특별시 버스도착정보 API로 전송됩니다. 전송된 좌표는 응답을 받는 즉시 사용되고 기기나 외부에 저장되지 않습니다.
  • 앱은 사용자의 위치를 지속적으로 추적하지 않으며, 백그라운드에서 위치를 수집하지 않습니다.
  • 위치 권한을 거부해도 지도에서 직접 정류장을 검색·선택하여 앱의 모든 기능을 이용할 수 있습니다.

집·회사 위치는 위치 권한과 무관하게, 사용자가 주소를 검색해 직접 선택한 지점이 기기에 저장되는 것입니다.

4. 외부로 전송되는 정보

본 앱은 실시간 도착정보 조회와 지도 표시를 위해 아래 외부 서비스를 호출합니다. 전송되는 정보에는 개인을 식별할 수 있는 정보가 포함되지 않습니다.

위 정보는 각 서비스의 요청 처리에만 사용되며, 본 앱은 그 결과를 사용자에게 표시하는 것 외의 용도로 활용하지 않습니다. 카카오 서비스로 전송되는 정보의 처리에 관한 사항은 카카오 개인정보처리방침을 참고해 주세요.

6. 제3자 제공 및 광고

본 앱은 광고 SDK나 사용자 행동 분석(Analytics) 도구를 사용하지 않습니다. 사용자 데이터를 광고나 마케팅 목적으로 수집·판매·제공하지 않습니다.

본 앱이 사용하는 제3자 구성요소는 지도 표시를 위한 카카오맵 SDK가 유일하며, 그 전송 내역은 4항에 기재되어 있습니다.

7. 데이터 보관 및 삭제

2항의 데이터는 앱을 삭제하면 기기에서 함께 삭제됩니다.

다만 Android 운영체제의 자동 백업 기능이 켜져 있는 경우, 앱 설정과 기록이 사용자 본인의 Google 드라이브 백업에 포함될 수 있습니다. 이는 Android가 제공하는 기능으로 개발자는 해당 백업에 접근할 수 없으며, 기기의 설정 > Google > 백업에서 사용자가 직접 관리하거나 삭제할 수 있습니다.

본 앱은 개발자 서버에 사용자 데이터를 보관하지 않으므로 별도의 삭제 요청 절차가 없습니다. 문의 사항은 9항의 이메일로 연락해 주세요.
