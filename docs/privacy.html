오늘도출근 개인정보처리방침

시행일: 2026년 7월 12일

「오늘도출근」(이하 "본 앱")은 사용자의 개인정보를 소중히 여기며, 관련 법령을 준수합니다. 본 방침은 본 앱이 어떤 정보를 다루고 어떻게 보호하는지 설명합니다.

핵심 요약
본 앱은 개인정보를 수집하지 않으며, 어떠한 데이터도 외부 서버로 전송하거나 제3자에게 제공하지 않습니다. 모든 데이터는 사용자의 기기 내부에만 저장됩니다.

1. 수집하는 개인정보

본 앱은 이름, 이메일, 전화번호, 계정 정보 등 개인을 식별할 수 있는 정보를 일절 수집하지 않습니다. 회원가입이나 로그인 절차도 없습니다.

2. 기기 내부에만 저장되는 데이터

아래 데이터는 앱 기능 제공을 위해 사용자 기기 내부에만 저장되며, 외부로 전송되지 않습니다.

데이터용도
알람 설정 (시각, 요일, 알람음, 진동 등)출근 알람 제공
미션 설정 (선택한 버스 정류장·노선, 목표 시각)타임어택 미션 및 실시간 도착정보 표시
미션 성공/실패 기록출근 기록 통계 표시
앱 환경 설정 (음성 안내 여부 등)사용자 편의 기능

이 데이터는 앱을 삭제하면 함께 삭제됩니다.

3. 위치 정보

본 앱은 출근 경로 설정 시 지도에서 내 위치 주변의 버스 정류장을 쉽게 찾을 수 있도록 위치 권한(ACCESS_FINE_LOCATION, ACCESS_COARSE_LOCATION)을 사용합니다.

  • 위치 정보는 정류장 선택 화면에서 지도를 내 위치로 이동하는 데에만 사용됩니다.
  • 위치 정보를 저장하지 않으며, 서버로 전송하지 않습니다.
  • 위치 권한을 거부해도 지도에서 직접 정류장을 검색·선택하여 앱을 이용할 수 있습니다.

4. 외부 API 호출

본 앱은 실시간 버스·지하철 도착정보를 표시하기 위해 공공데이터포털의 공공 API (서울특별시 버스도착정보, 서울교통공사 지하철 도착정보)를 호출합니다. 이때 전송되는 정보는 사용자가 선택한 정류장·노선 식별자뿐이며, 개인을 식별할 수 있는 정보는 포함되지 않습니다.

전체 화면 알림 (USE_FULL_SCREEN_INTENT)알람이 울릴 때 잠금 화면 위에 알람/미션 화면을 즉시 표시
포그라운드 서비스알람음 재생 및 미션 진행 중 실시간 도착정보 갱신

알림 (POST_NOTIFICATIONS)알람 및 미션 진행 상태 알림 표시

6. 제3자 제공 및 광고

본 앱은 개인정보를 제3자에게 제공하지 않으며, 광고 SDK나 분석(Analytics) 도구를 사용하지 않습니다.

7. 아동의 개인정보

본 앱은 개인정보를 수집하지 않으므로 아동의 개인정보도 수집하지 않습니다.
